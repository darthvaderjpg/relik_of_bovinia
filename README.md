# Relik Of Bovinia
Last Revision Date: (10/29/2026). 

This is a Zelda Based Action game where you can fight enemies, drink potion, and become stronger to fight an evil cow. 

Everything is for Grandfather...

Bovinia is your home. Protect it.

Traverse the lands and kill the stupid looking cow gargoyle. (Yes it was originally meant to look like a gargoyle but then my friends said it looked like a cow)
